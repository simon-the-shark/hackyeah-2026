## 18. Error Code Quick Reference

| Error code | Description |
|------------|-------------|
| 100003 | Router page stack exceeds 32 pages |
| 100005 | Navigation page has no registered builder |
| 100006 | Navigation page has no NavDestination |
| 100021 | Declarative FrameNode cannot be modified |
| 106203 | Operation on an unmounted node |
| 130000 | addMonitor/clearMonitor target must be an @ObservedV2 class or @ComponentV2 instance |
| 130002 | addMonitor/clearMonitor callback must be a named function |
