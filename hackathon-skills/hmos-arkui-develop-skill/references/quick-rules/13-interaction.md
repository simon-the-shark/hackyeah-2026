## 13. Interaction and Gesture Constraints

| Rule | Description |
|------|-------------|
| Long press and drag conflict | Simultaneous gestures may conflict; consider priority |
| onDragLeave limitation | onDragLeave does not fire in some scenarios |
| Anonymous-function this issue | ArkTS does not allow anonymous event handlers; use arrow functions |
| bind(this) not recommended | Do not configure event handlers by binding member functions with bind(this) |
