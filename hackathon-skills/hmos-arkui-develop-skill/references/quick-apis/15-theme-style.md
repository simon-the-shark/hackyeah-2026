## 15. Themes and Styles

| API | Signature | Description |
|-----|------|------|
| **WithTheme** | `WithTheme({theme}) { ... }` | Bind a theme to a subtree |
| **@Styles** | `@Styles function name() { .width(100).height(100) }` | Extract reusable styles |
| **@Extend** | `@Extend(Component) function name(params) { ... }` | Component extension method |
| **@StateStyles** | `@StateStyles({ normal:{}, pressed:{}, disabled:{}, focused:{}, selected:{} })` | Polymorphic styles |
