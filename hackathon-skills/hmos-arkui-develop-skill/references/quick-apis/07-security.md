## 7. Security Components

### SaveButton / PasteButton

Permission-free security buttons.

**Constructor:**

```typescript
SaveButton(options: SaveButtonOptions)
PasteButton(options: PasteButtonOptions)
```

**Common properties and methods (specific to Security components):**

| Method | Description |
|------|------|
| `.iconColor(color)` | Icon color |
| `.fontColor(color)` | Font color |
| `.bgColor(color)` | Background color |
| `.borderWidth(Length)` | Border width |
| `.borderRadius(Length)` | Corner radius |
| `.iconSize(Size)` | Icon size |
| `.fontWeight(FontWeight)` | Font weight |
| `.fontSize(Length)` | Font size |
| `.fontStyle(FontStyle)` | Font style |
| `.description(ResourceStr)` | Description text |
| `.textIconSpace(Length)` | Text-icon spacing |
